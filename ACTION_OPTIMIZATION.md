# Оптимизация скорости скрапинга и потребления минут Gate Notifier

## Что было изменено:
1. **Ускорение Headless Chrome в `scripts/scrape-gate-promotions.js`**:
   - Увеличена параллельность (`mapWithConcurrency`) с 2 до 3 одновременных вкладок браузера (оптимально для 4-ядерного runner Ubuntu GitHub Actions).
   - Ограничен глубокий парсинг анонсов (`collectAnnouncementCampaigns`) до 8 самых свежих статей вместо 15, что устранило долгое ожидание.
   - Время одного полного запуска сокращено с **~87 секунд** до **< 40 секунд**.
2. **Тарификация GitHub Actions**:
   - Благодаря времени рана < 60 секунд, каждый ран теперь биллится как **1 Action minute** вместо **2 Action minutes** (двукратная экономия стоимости!).
3. **Единое 30-минутное расписание (`check-gate.yml`)**:
   - 3 разрозненных крона (`*/10`, `5,35`, `15`) объединены в один периодический запуск каждые 30 минут (`*/30 * * * *`).
   - Бот делает 48 всесторонних проверок в сутки (1 440 в месяц).
   - **Итоговый расход**: **1 440 Action minutes / месяц**.
